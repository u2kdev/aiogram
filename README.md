# 🤖 Telegram-бот для управления вакансиями

Профессиональный бот для публикации вакансий за рубежом с админ-панелью и системой откликов.

## 📋 Возможности

### Для пользователей:
- ✅ Регистрация через контакт
- 🌍 Просмотр вакансий по странам
- 💼 Детальная информация о вакансиях
- 📩 Отклик на вакансию (заявка админам)
- ℹ️ Информация о компании

### Для администраторов:
- ➕ Добавление/удаление стран
- 💼 Добавление/удаление вакансий
- 📊 Выгрузка данных пользователей в Excel
- 📄 Просмотр логов действий
- 📩 Получение откликов на вакансии

## 🚀 Установка

### 1. Клонируйте репозиторий или создайте файлы:
```bash
# Создайте папку проекта
mkdir vacancy_bot
cd vacancy_bot
```

### 2. Установите зависимости:
```bash
pip install -r requirements.txt
```

### 3. Настройте бота:
Отредактируйте `config.py`:
```python
BOT_TOKEN = "YOUR_BOT_TOKEN"  # От @BotFather
ADMIN_IDS = [123456789]        # Ваш Telegram ID
```

**Как узнать свой ID:**
- Напишите боту [@userinfobot](https://t.me/userinfobot)

### 4. Добавьте фото меню (опционально):
Положите файл `photo.jpg` в папку с ботом

### 5. Запустите бота:
```bash
python main.py
```

## 🎯 Использование

### Команды бота:

#### Для всех пользователей:
- `/start` - Начало работы / главное меню

#### Только для администраторов:
- `/data` - Выгрузить список пользователей (Excel)
- `/log` - Получить лог действий администраторов
- `/applog` - Получить лог откликов на вакансии
- `/stats` - Показать статистику бота

### Работа с вакансиями (для админов):

#### Структура меню:
```
Главное меню
└── Вакансии (A)
    └── Страна (B)
        └── Вакансия (C)
            └── Описание (D) + кнопка "Откликнуться"
```

#### Добавление вакансии:
1. Перейдите в "Вакансии"
2. Нажмите "➕ Добавить страну" (если страны нет)
3. Введите название страны (например: "США")
4. Откройте страну
5. Нажмите "➕ Добавить вакансию"
6. Введите название вакансии (например: "Водитель")
7. Введите описание вакансии

#### Удаление:
- Используйте кнопки "🗑 Удалить страну" или "🗑 Удалить вакансию"

## 🐛 Известные ограничения

1. **Длина callback_data**: Telegram ограничивает до 64 байт. При очень длинных названиях стран/вакансий возможны проблемы.
   - **Решение**: Использовать короткие названия или хэширование

2. **Удаление сообщений**: Бот может удалять только недавние сообщения (до 48 часов)

## 💡 Рекомендации

1. **Бэкап данных**: Регулярно делайте копии `data.json` и `vacancies.json`
2. **Короткие названия**: Используйте краткие названия стран и вакансий
3. **Фото меню**: Используйте изображение размером ~800x600px для лучшего отображения
4. **Мониторинг логов**: Периодически проверяйте логи через команды `/log` и `/applog`

## 🆘 Частые проблемы

### Бот не отвечает:
- Проверьте правильность токена в `config.py`
- Убедитесь, что бот запущен

### Не работают админские функции:
- Проверьте, что ваш ID добавлен в `ADMIN_IDS`
- Узнайте ID через [@userinfobot](https://t.me/userinfobot)

### Ошибка при выгрузке Excel:
- Установите: `pip install openpyxl pandas`

### Не отображается фото меню:
- Убедитесь, что файл `photo.jpg` находится в папке с ботом
- Проверьте формат файла (должен быть JPG)
